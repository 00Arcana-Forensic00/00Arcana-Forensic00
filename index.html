Acquire

Confined directory walk — no symlinks, no device nodes followed. SHA-256 every file before it's touched.

Seal

AES-256-GCM into a versioned vault blob. Key derived from your passphrase, never stored in the case directory.

Custody

Every action appended to a local SHA-256 hash chain in SQLite. verify re-hashes and re-checks it end to end.
