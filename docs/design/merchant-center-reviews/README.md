# Merchant Center + Reviews design

Two-artboard mock-up (1280×860) for a Google Merchant Center overview and a product reviews screen.

- `Main.dc.html`: overview (KPI tiles, product status, needs-attention list)
- `Reviews.dc.html`: average rating, 1–5 star breakdown, recent reviews
- `canvas.json`: canvas layout index

All figures, names and review text are bracketed placeholders (e.g. `[000]`); no real data.
Source files for the Design artifact; they render only in that editor, not as standalone pages.
